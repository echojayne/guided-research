# 飞书调研报告模板参考

默认使用下面的模板映射；仅在组织或更新报告时读取。用户另行指定模板或要求同步最新版时，以其要求为准，使用 lark-doc 读取对应范围；遇到嵌入表格再用 lark-sheets 读取字段。

这是已确认调研规范的独立模板映射，初版日期：2026-10-12。使用者可提供自己的飞书模板替换本映射。

## 正文章节与填写要点

**摘要**：一页以内，简要交代调研目标、主要结论、关键依据、未确定事项和下一步行动。关键判断与正文一致，并注明适用边界。

**一、调研背景与目标**
- 1.1 研究背景：聚焦具体对象、问题与价值。
- 1.2 调研目标：列出本次要回答的问题或做出的决定。
- 1.3 调研范围与资料来源：简述方向或问题、场景、时间范围、资料来源及检索截至时间；方法细节按需要交代。

**二、研究现状与代表性工作**
- 2.1 研究工作分类：按问题、核心思路或技术路线归类。
- 2.2 代表性工作分析：基本信息、研究问题、核心方法、主要结果与支撑证据、优势与局限、与调研目标的关系。按相关性决定分析深度，工程资料记录版本或更新时间。

**三、已有工作的对比分析**
- 3.1 方法对比。
- 3.2 实验效果对比：有可比结果时填写；理论或缺少定量证据的工作可说明原因，进行理论或定性比较。表后交代数据划分、场景、训练预算、模型规模、指标算法、硬件与测量条件等影响判断的口径差异。
- 3.3 综合分析：解释路线之间的关系、适用条件、主要限制和权衡。

**四、现有局限与进一步研究或应用机会**：问题、证据、最接近的已有方案、仍需研究或验证的原因。按目标梳理开放问题、判断研究机会或分析方案适配需求；检索范围内的缺项应如实标注。

**五、调研结论与下一步计划**
- 5.1 调研结论：逐项回应目标，交代依据、边界和不确定性。允许已有方案足够、问题尚未确认、暂不能推荐或证据不足等结论。
- 5.2 下一步计划：了解方向可结束本阶段或补查分歧；确定方向说明问题价值与可行性；科研问题安排必要验证；工程问题提出选型和适配测试。区分问题验证与方法验证，说明依据什么结果继续、调整或停止。

**六、参考文献**：重要观点、结果对应原始论文或技术资料，给出来源链接和必要的证据位置；工程资料注明版本或更新时间。实际未实施的实验、无法核查的引用或结果不得写成已完成的事实。

## 表格字段

沿用字段，新建报告自己的表格；按资料填写具体内容，删除示例占位。适用性不足的表格说明原因。

| 表格 | 字段 |
|---|---|
| 摘要 | 内容、要求；覆盖调研目标、主要结论、关键依据、未确定事项、下一步行动 |
| 分类 | 研究类别、核心思路、代表性工作、主要特点 |
| 方法对比 | 代表性工作、解决的问题、核心方法、主要优势、主要局限 |
| 实验效果 | 方法、数据集、评价指标、实验结果、计算或资源成本 |
| 下一步计划 | 待确认的判断、验证任务与条件、判断标准、预期产出 |

工程资料在“数据集”字段中可以说明实际测试数据或场景。摘要可以写成连贯短文，其余表格按目标选用；对比表的实验口径差异放在正文说明。

## 交付自查

模板末尾的填写说明用于自查，通常不复制进报告正文。核对：目标明确、分类合理、内容准确、对比充分、分析客观、结论清晰、计划具体、来源可追溯。在线回读时同时核对表格与链接，保留仍未解决的关键不确定性。
